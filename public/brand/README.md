# TUNG web brand assets

Production-safe raster exports derived from the approved `TUNG-LogoKit-v1.0` panels.

- `tung-wordmark-on-dark.png`: recropped from `modules/LK-01_primary_wordmark_panel.png`.
- `tung-horizontal-lockup-on-dark.png`: rebuilt from the approved wordmark without the retired domain lockup.
- `tung-icon-on-dark.png`: recropped from `modules/LK-04_icon_mark_panel.png`.
- `tung-wordmark-on-light.png`: recropped from the approved light reference in `modules/LK-08_logo_variants_panel.png`.

The supplied standalone transparent files were not used directly because their crops remove required clear-space. Geometry is unchanged; transparent padding was added and colors follow the supplied brand tokens (`#C8FF4D`, `#F4F4F2`, `#111317`).
